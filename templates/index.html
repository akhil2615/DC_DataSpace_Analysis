Data Cloud Data Space Analysis Launcher

Generate the analysis document and download a workbook bundle of retrieved metadata.

First-Time User Walkthrough

Follow this once per machine.
  1. Run the setup script for your operating system.
  2. Start this launcher (`python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload`).
  3. Click Check Setup.
  4. Click Load Latest Data Spaces.
  5. Select one data space and click Generate Analysis Files.
  6. Download both outputs: analysis document and metadata workbook.
Quick setup commands
Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File scripts/setup_windows.ps1
macOS / Linux
chmod +x scripts/setup_unix.sh ./scripts/setup_unix.sh
